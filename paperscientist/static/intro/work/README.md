# Welcome Work gallery

Motion reference: the Work chapter of [Wodniack](https://wodniack.dev/), checked against the user's recording: bowed red corridor, vertical WORK capsule, concave repeated letter wall, pointer-spawned previews, then the reverse capsule exit. This is an independent implementation; no website source, project screenshots or proprietary fonts are bundled.

The six SVGs and condensed letter outlines were authored for PaperScientist. They illustrate research capabilities, not completed user projects or empirical findings. In particular, `figures.svg` is a conceptual curve, not a result plot. Each preview is labelled as an illustration in the UI and accessible text.

The warp uses the user's local `095-starfield-warp` reference (400 projected stars and five speed levels), adapted to the shared, reversible journey clock. There is no second animation loop, external CDN, additional WebGL context or postprocessing framebuffer. The warp drawing buffer is capped near 2.6 million pixels; the gallery has 21 letter planes and five reusable preview slots. Hidden scenes skip drawing. Mobile layouts show fewer letter planes. Reduced motion disables travel/parallax and gives stationary selectable previews.

The seven chapters contain eleven wheel stops: valley → literature → observatory → warp → nebula → Work capsule → three gallery beats → capsule exit → dawn. The original nebula, meteors, camera, hands and music remain in their established renderer; an explicit coordinate mapping inserts the new beats. Keyboard navigation remains instantaneous.
