# 已升级为用户指定领域的研究工作流

主 skill 已更名为 **`research-obsidian`**，支持用户指定任意研究领域，不再固定为 AI 安全。

- [新版安装与使用说明](../research-obsidian/README.md)
- [下载新版 skill 包](../packages/research-obsidian.skill)
- [旧配置兼容说明](../research-obsidian/references/compatibility.md)

首次使用示例：

> 使用 $research-obsidian。研究领域是「我的研究领域」，关注「关键词」，排除「不需要的内容」。Obsidian 仓库是「绝对路径」。请初始化并创建每天收集论文、同步知识图谱的定时任务。

此目录只保留旧调用名和 workflow.py 的转发入口，需要相邻的完整 `research-obsidian` 目录。
