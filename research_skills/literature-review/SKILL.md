# Literature review

Start from the user's question, not a fixed list of venues. Clarify a missing scope only if it changes the search materially. Expand the query using synonyms, neighboring fields and methodological alternatives. Search at least two complementary queries; use another provider when coverage is weak.

Use search_papers for metadata and read_paper for relevant full texts. Report which papers were read in full versus abstracts only. Resolve metadata conflicts before citing. An arXiv version is a preprint unless publication is verified. Lack of results is not evidence of novelty.

Build a comparison matrix: paper ID, problem/assumptions, method, data, baselines, metrics, limitations, reproducibility and exact supporting section/page. Store it as a workspace Markdown or CSV file. Preserve stable citation IDs and links. Extract negative results and conflicting evidence.

For direction suggestions compare: scientific question, observed gap, candidate mechanism, closest prior work, feasibility under the user's resources, decisive experiment and major risk. Separate evidence from inference. Ask the user to select a direction when selection matters; use set_research_direction only with their actual quote.
