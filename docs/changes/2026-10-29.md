## 金鱼远离水波方向修正

修复上一版仅沿原有巡游方向加速、可能靠近水波的问题。保存点击位置，选择使距离增加的逃离方向，平滑转身后再加速；转向期间取消自动巡游漂移，到泳道远端后等待，不在受惊期间绕回水波。连续换边点击从当前姿态重新规划，保留避碰和水域边界。

验证：95 项 Node 测试和 2 项 Python 页面/资源测试通过。新增八方向、多相位、窄屏/桌面/4K 的距离不减检查和交替换边点击检查，覆盖实际退开、转向连续和重复触发。网页点击向左游动的金鱼左侧水面后，确认水波及受惊状态触发、鱼向右游开，数量保持 6；页面错误日志为空，四个运行文件与 E:/agent 一致。

限制：可逃离距离受原有独立泳道与水域边界约束，到达远端会等待；仍使用原绘制层和固定鱼群，没有新增资源。浏览器后台限帧仍不能用作真实前台帧率结论。

## 金鱼受惊后自然游开与停转修复

取消狭窄椭圆泳道上的反向等待，改为在水域内持续游动。点击后边弯身摆尾、边转弯加速，短促游开后平滑减速，继续巡游；在转弯预测中同时考虑岸边和其他鱼，修复原地旋转超过半圈、转身慢及到远端停住。重复点击保留当前位置、速度和航向。

验证：95 项 Node 前端测试、2 项 Python 页面/资源测试通过。510 种点击方向/相位/尺寸组合在 1.5 秒时均拉开与点击点的距离，继续检查至 5 秒，无超过约 150 ms 的停滞；五种尺寸各 1800 帧重复点击保持鱼群间距与水域边界。实际网页点击确认受惊状态触发并恢复，6 条鱼保持显示且继续移动，页面错误日志为空；四个运行文件与 E:/agent 一致。

资源：复用原画布与动画时钟，固定 4/6 条金鱼。独立运动模拟每尺寸预热 300 帧、测量 2400 帧，平均更新 0.096–0.142 ms，95 分位 0.131–0.182 ms。此数值不包括 Canvas 和 GPU，浏览器后台限帧不能代表真实前台流畅度。沿岸自然弧线允许短暂靠近水波，方向验证改为实际游开、转向连续和不停住，替代容易鼓励原地等待的逐帧距离不减规则。
