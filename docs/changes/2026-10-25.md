## 科研专家、基准协议与可验证论文交付

加入可扩展的文献、构思、设计实现、实验评估和写作专家，以及受父能力范围限制的检索/通用叶子代理。LangChain 绑定与执行双重限制工具，技能目录、资源和 staging 同步限权；嵌套等待不占执行名额，支持递归取消、重启恢复与逐级产物哈希核验。普通和持久运行都执行可扩展的前置、后置及完成检查。

论文写作优先使用 FigureForge 参考图库适配器与本地可复现矢量绘图；新增首稿章节审查、学术润色与 anti-defensive-writing。对 motivation/challenge 的例子、贡献与设计映射、实验设置、基线/消融/失败分析提出具体要求，保留证据不足的部分。适配器使用图库和本地绘图器，没有冒称调用上游图像模型。

版式契约保存在数据库，JSON 为镜像；单/双栏等明确用户约束的变更需要可追溯指令。编译检查实际页面、栏宽、越界和图内字号，失败时保留此前 PDF。示例修订稿为 18 页 A4 单栏竖版，框架与例子图最小字号约 10.04 pt，结果图约 8.04 pt；4 份 CSV 哈希与原版一致。

基准机制支持适用性判断、官方来源收集、版本/许可/划分/指标登记、运行前协议与输入哈希冻结、执行及结果审计。真实本地适配器验证完成 24/24 个合成评价单元，结果只说明本地协议链路有效，不是 ScienceAgentBench 等外部基准成绩，也不是新科研结果。

DeepSeek 实测跑通主代理→设计专家→两个并行叶子：40 个真实 unittest 用例、逐级导入及重跑通过。新增负对照后完成检查要求重新运行正向测试，原任务经 followup 恢复并完成。测试认证使用实际 unittest/pytest 事件与执行/源码哈希，单纯打印成功文字、子进程输出或预期失败负对照不能充当成功证明。

验证：最终 130 项 Python 测试、9 项子测试和 28 项前端检查通过。正式服务已重启，研究会话快照（消息、项目记忆、产物等）哈希一致；新 benchmark 技能可通过网页 API 读取。

提交：[ad3c6c3 — Add scoped research agents and evidence-checked paper delivery](https://github.com/colinLH/PaperScientist/commit/ad3c6c3cebff5893d01e0d4e11585973e29d12d6)。
