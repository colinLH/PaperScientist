## 跨页滚动边界停顿与全屏双幕布限制

修复滚轮事件短暂停顿后被重复当成新翻页、目标页持续累加的问题。跨页时先到达当前目标附近，再保留约 180 ms 的边界停顿；页外以 320 ms 安静间隔区分新手势。过渡期间的同向输入直接消耗、不排队，反向回撤仍保留镜头速度连续性。Work 页内继续按滚动距离连续推进和倒回，只有入口、出口有边界保护；减少动态效果模式也可继续翻页，不依赖空闲动画帧解锁。

Work 保留六个论文项目和上下两条轨道，拉开相邻幕布的间距：上一幅完全离开视野后下一幅再进入，每排最多一幅，整屏最多两幅，包括只露出边角的部分幕布。所有论文仍可滚动浏览或通过编号定位，正反向使用同一位置函数。

验证：40 项 Node 开场回归和 2 项 Python 资源/路由测试通过；新增覆盖分段惯性、过渡期间不累积翻页、到达后的停顿、反向回撤、减少动态效果、Work 连续小幅滚动，以及五种窗口尺寸下包含边角的全屏可见幕布上限。正式网页实测从第三页快速下滚只进入相邻页，向上只回退一页；Work 从 6 到 7 再倒回 6，全部幕布坐标与起点一致；三组论文分别可见且每次不超过两幅。正式资源已更新。未宣称对所有触控板、真实手机和浏览器完成实机兼容测试。

## 引力空间扭曲、4K 星图与 Work 逐列滚动

第四页在原星际穿梭上加入有限中心的引力透镜、弯曲星轨和椭圆空间轮廓，继续使用固定 400 颗星、五档速度与原像素预算。第五页保留原 4K 蓝色星云和流星，重新绘制 16 个矢量星点、四个带环形刻度的导航枢纽、21 条主连线及 10 条次连线；节点增加白色核心、衍射光芒与细环，主次线路使用不同亮度和流动光效，沿用静止时原生最高 3840×2160 的渲染策略。

以用户提供的本地 142-gravity-particles 示例为参考，为 Work 入口和出口加入 420 个固定粒子、轨道拖尾、九层轮廓和中央暗色引力场。粒子收拢程度与原聚焦/展开镜头共用进度，展开时渐隐，退出时反向恢复；轻微鼠标视差增加空间感。共用原画布和时钟，入口静止目标为每秒 30 次更新，展开后静止停止绘制，不新增后处理缓冲或 WebGL 上下文。

Work 页内由连续距离滚动改为一次手势推进一列，幕布与字墙共享列间距；较大滚轮输入与后续惯性不再连续推进多列。小幅触控板事件累积到阈值后推进一次，反向可立即回退。为了保留“展开后滚动几下再出现首幅”的节奏，前后空场改为各约 3%（按窗口约两到四次手势），继续下、上交替交接，整屏最多两幅，跨页边界保护不变。

验证：45 项 Node 开场测试和 2 项 Python 路由/资源测试通过。正式网页在 1280×720 下实测一次滚轮将首幅幕布从 x=443.440 移至 348.016，距离 95.424 像素恰为一列；倒滚回到 x=443.440。检查初始空场、入口引力场、第四页透镜、第五页星图及 390 像素窄屏，无脚本错误；4K 浏览器视口实测绘制缓冲为 3840×2160，保存原尺寸截图。受控预览中两次各约 8 秒测量：入口引力场绘制 240 次、展开静止字墙绘制 0 次，均无超过 50 ms 的主线程长任务。正式资源与提交文件逐一比对一致。

限制：引力效果是艺术化视觉设计，不是广义相对论模拟。4K 验证指浏览器视口与绘制缓冲，性能数字限于本机测试，未测所有触控板、真实手机或低端 GPU；未新增摄像头实机验证。六个论文预览仍依赖官方外部媒体及浏览器播放策略。
