开场扩展为七个章节、十一个滚轮停点。所有新增场景接入原镜头与音频进度，同一路径支持正反向滚动；原 4K 星云、流星、雾效、手势与声音默认设置保留。新绘制沿用一个限帧时钟，完全被遮挡的背景跳过绘制，穿梭画布约 260 万像素上限，21 个固定字墙平面与最多五个预览节点，退出释放资源。提供键盘选择、减少动态效果模式及窄屏字墙布局。

验证：30 项 Node 开场测试、2 项 Python 路由/资源测试通过，覆盖扩展镜头与音乐连续性、滚轮惯性、途中反向、预览池上限、缩放后预览位置、减少动态效果和资源释放。正式网页检查了穿梭/速度选择、原星云、作品展开/收束、倒滚重入、最终 Start，以及 390/680 像素布局和窗口缩放；修复了焦点导致整个场景滚动、缩放后预览偏离中心的问题。正式资源已更新，无浏览器控制台错误。未进行跨浏览器、真实手机或低端 GPU 帧率基准；当前测试设备未检测到摄像头，因此没有重新宣称完成实机手势测试。展示动画为依据参考重新实现，并非复制原站源码、字体或第三方项目图片。

## Work 双轨论文预览、滚动联动与流畅度优化

根据用户录屏和进一步说明，将鼠标触发、定时下滑消失的预览改为上下两条平行轨道，每排三个固定幕布。滚轮距离连续控制幕布和凹曲 WORK 字墙向左环绕，停止滚动后位置不变；倒滚沿同一路径返回，只在屏幕外循环复位。入口和出口改用更快的弹簧响应与集中展开曲线，反向时保留当前位置及速度；保留原星云、流星、音乐和其它章节。

接入 Nerfies、HyperNeRF、DreamFusion、Zip-NeRF、Mip-NeRF 360、Ref-NeRF 六个官方论文项目的视频与封面，点击可打开原站。每排仅播放中央一个预览，其余显示封面；暂停、收回、离开、隐藏页面时卸载视频。预览采用官方媒体组成的小型项目页面，不执行第三方完整网页；媒体来自作者服务器、需要联网，失效或自动播放被拒绝时显示封面/原站入口。修复了 Zip-NeRF 官方 OG 封面失效，改用作者主页的对应论文封面。

将大量逐帧变化的 SVG 平面合并为一张缓存字形的画布，约 220 万像素上限；轨道仅更新位移，Work 运动时目标 60 次场景更新/秒，稳定后停止重绘。相同设备、1280×720 浏览器、8 秒相同前进/后退轨迹的一次对照中，原版 177 次场景更新，新版 480 次；95% 更新间隔从 62.5 ms 降至 25 ms，两次均无超过 50 ms 的主线程长任务。静止五秒检查字墙重绘为 0、幕布坐标不变，仍正常播放两路视频。以上为本机场景绘制节奏测量，不是 GPU 占用或低端设备通用帧率保证。

验证：36 项 Node 开场回归和 2 项 Python 资源/路由测试通过。覆盖 390/680/1280/2160/3840 宽度的轨道无重叠、屏幕外循环、连续滚动/惯性/反向、像素预算、视频并发上限、播放竞态及失败重试。浏览器实测正滚后等量倒滚坐标一致；正式网站在 2157×1244 下检查六个封面、双路真实视频播放、暂停/恢复、入口收束和最终 Start；退出时视频源全部卸载。正式健康检查正常。未测真实手机、其它浏览器或低端 GPU。
