## 第二幕全球主要城市旋转地球

根据用户指定的 Three.js 地球文章，将第二幕从抽象知识球面替换为实体地球。采用 Natural Earth v5.1.2 公有领域海岸线与城市坐标，展示六个有人居住大洲的 41 座主要城市；本地保存精简数据、来源链接和原始文件 SHA-256。增加蓝色海陆轮廓、经纬网、大气边缘、缓慢云层与扫光、城市光柱及涟漪、动态弧形连线和两条卫星轨道。连线明确标注为探索示意，不代表实际航线或研究合作数据。

保留持续自动旋转，约 84 秒一周；鼠标拖拽叠加平滑旋转偏移，选择城市沿最短方向转到其位置，显示中英文名称和经纬度。可点击可见标记及标签，也可从城市列表访问全部 41 座城市。桌面最多八个、手机最多四个朝向镜头的标签，自动避让；第一、第三幕、WORK 和原版结尾保持原功能。减少动态效果时停止环境自转，保留直接交互；离开第二幕停止该场景绘制。

性能与验证：城市点、光柱、涟漪和移动光点采用实例化绘制，实际场景约 23–24 次绘制调用；新增地球画布限制在 220 万像素，复用已有页面时钟，无额外动画循环，无运行时外部地图请求。59 项 Node 测试及 2 项 Python 路由测试通过，git diff --check 通过。测试覆盖六大洲坐标、飞线球面外插值和日期变更线、城市定位、正面标签避让、场景淡入淡出、统一时钟及释放。正式网页验证自动旋转、拖拽、标签点击、上海/纽约/悉尼定位、重置以及第三幕恢复；1920×1080 桌面和 390×844 手机尺寸均实看，手机无横向溢出，显示四个标签。十二个交付文件与运行目录逐一一致，当前版本无新增脚本错误。

限制：城市为跨洲策展选择，并非全球人口排名或穷尽列表；地理坐标精度遵循 Natural Earth 数据，云层与卫星为艺术表现。WebGL 不可用时保留投影城市降级效果，不具备完整地理表面与高级特效。本次未开展真实手机触屏、低端 GPU 或 4K 帧率基准，不将绘制次数当作 FPS 测量结果。

## 非防御性协作与材质化叙事开场

在主 Agent 和研究子 Agent 的系统提示词中加入原句：“如果某句话的作用只是防止被质疑，而不是推进论证，请删除。”应用于进度、回答、审阅和论文表达，要求直接呈现论点、证据与下一步；影响判断的真实不确定性、失败检查和必要边界仍需保留。运行服务已重启加载更新。

welcome 第一幕与第三幕改为原创 Three.js 材质装置，替换主要的粒子波浪与行星视觉。第一幕以具有厚度、扭转和金属反射的连续光带表达线索浮现；第三幕以六层玻璃透镜、金属边框、细刻度和汇聚光路表达问题、方法、数据、实验、评估和表达。用墨蓝、银灰、纸白与少量香槟色，搭配中文衬线标题与留白；文字连接“提出问题 → 全球知识 → 方法与证据 → 更远探索”的叙述。保留拖拽、点亮线索、点击透镜、键盘操作、流速调整和重置，选层会展开间距并给出阶段解释。

一个新增渲染器服务两幕，复用页面时钟，画布上限 220 万像素；第一幕实际 3 次绘制、第三幕 39 次绘制，不添加独立动画循环或辉光后处理。离开时停止该场景绘制，退出释放几何、材质、反射贴图、监听器与 WebGL 上下文；减少动态效果保留选择反馈。反射环境由本地程序生成，无外部图片或运行时新依赖。

验证：62 项 Node 测试和 18 项 Python 路由/Agent 配置测试通过，git diff --check 通过。真实网页验证点亮反馈、鼠标拖拽、点击实验透镜与解释、地球衔接、离开至第四幕后隐藏，以及服务重启后的访问；2157×1244 桌面与 390×844 手机尺寸实看，手机无横向溢出。新测试覆盖几何法线与顶点预算、透镜顺序、双向淡入淡出、统一时钟、选择传递、隐藏停止与释放。九个交付文件与运行目录核对一致，当前版本无新增浏览器脚本错误或警告。

限制：光带和透镜是科研过程的视觉隐喻，不是光学仿真；WebGL 不可用时仍使用原有轻量绘图。手机为浏览器尺寸模拟，未开展手机实机、低端 GPU 或 4K 帧率基准；绘制次数不是性能提升结论。提示词已接入，不将结构测试表述为所有模型输出均已达到写作要求。
