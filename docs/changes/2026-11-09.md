## 论文配图与 MicuAPI 概念插图

实验图按稿件栏宽安排面板和图注，系列在不同面板中沿用颜色与标记。横向点区间图直接读取 CSV 中的估计值与误差。可编辑框架图保留矢量和 draw.io 源文件。概念插图可以把单独的绘图说明发给 MicuAPI，归档 PNG、指定尺寸的 PDF、绘图规格和生成记录。聊天和绘图服务分别从本机配置读取密钥；仓库模板中的密钥字段均为空。

本机使用相同的规格和 CSV 对比了新旧单栏 PDF，并检查了区间图。以来源标记为主题的概念图实测使用 `gpt-image-2.6-sunburst`：聊天端点明确返回 404 Unknown endpoint 后，同域图像端点成功返回 1774 × 887 像素，按 6.8 × 3.4 英寸导出了 PDF。图中的三个标签和两条路径已目检；盾牌代表来源检查，不能作为内容正确性的证据。

代码提交：[f5aca3b](https://github.com/colinLH/PaperScientist/commit/f5aca3be1e3440aadd7a95630097659bf4406d0c)。

## 每个会话的论文进度

工作台展示选题、文献、设计、实验、撰写、审阅和交付七个节点。运行中的当前阶段顺时针旋转，等待或暂停时静止。阶段报告、工具记录、直属子任务和产物均按会话读取。同项目的不同对话可各自处在不同阶段；已有活动和已完成里程碑分别标记。

在 1280 和 390 像素视口验证了运行、排队、暂停、等待回答、刷新、切换会话和减少动画设置。实际部署的工作台成功为已有的论文会话恢复了七个节点与“已交付论文”状态。仓库 tests 目录的 Python 测试通过 182 项、跳过 1 项；98 项 Node 测试通过。

## 分组实验与配对基线

评估专家可以在运行前从固定数据索引声明分组维度，并为不同方法指定各自的基线。审计按相同案例和种子的成功交集计算两侧指标及差值，同时保留计划分母、超时、错误和缺失。

通过实际工具调度执行了 24 条合成适配器试验。旧协议的 2,400 条冻结记录回放得到与历史回执完全相同的汇总。

## 分块框架图与多面板结果图

框架图支持按模块分别调用 MicuAPI，也可以复用已有图片。组版支持矢量标题、标签、连线和从原图裁出的局部放大。结果图支持在两个分组维度上展示共用量纲和刻度的雷达小多图，并区分缺测与零值。

以三幅独立生成的插图制作五面板框架图，验证了组图工具的登记和离线重绘。对已有的探索性检测器实验按四种检测器、三个训练划分重新作图，逐例核对五项比率的分子和分母。

## 紧凑的论文机制框架图

论文撰写专家优先按实际操作、数据字段和决策分支组织方法框架图。矢量绘图工具可并排安排阶段、展开小表格、高亮关键单元格，并将同一分支的候选路径并排绘制。SVG、PDF 和 draw.io 保留可编辑的文字与连接。

## 研究路线、跨项目基线与后台实验

对照 DeepScientist 的固定源码版本后，将分叉理由、停止原因、证据比较与可复用基线接入现有会话。工作台支持选择源实验、生成引用、跨项目核验及对照。只有口径匹配、完整且相互独立的实测运行才能计算差值。直接评估专家的回执可供本路线使用，隔离盲审材料仍按原有权限访问。

复现任务可以从公开仓库的固定提交、指定源码、PDF 或已有产物开始。命令行与网页操作同一研究任务。Python 和预注册评估可以在后台运行最多 24 小时，持续保存日志，完成后记录执行回执。可按任务选择飞书状态订阅。功能差异、适用场景与实际操作见[工作流对照](../deepscientist-comparison.md)。

本地验证了服务重启后取回后台实验、真实 Git 对象校验、预注册结果登记，以及桌面和手机工作台上的跨项目独立运行比较。Python 通过 204 项和 27 个子测试，一项中文字体检查因测试环境未检测到适用字体而跳过。Node 通过 98 项。飞书机器人订阅使用模拟端点验证。本机服务已在空闲时重启，首页、工作台、两个已有项目的路线接口和健康检查均通过。
