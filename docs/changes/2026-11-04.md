## WORK 作品展廊连续滚动

展开的作品展廊按滚轮位移连续移动。典型的 100 像素输入推进约三分之一屏，长滚可以连续经过多个作品。反向滚动从当前画面重新定向。进场和退场仍需在边界停稳后用新手势触发。

本机验证：95 项欢迎页 Node 测试通过，覆盖小步触控输入、持续滚动、反向、边界停顿、可见幕布及视频数量。在本机 8888 欢迎页的桌面无头 Chrome 中，从第 8 项连续发送 12 次同向滚轮输入到达第 18 项，反向 8 次回到第 11 项，始终停留在 WORK 幕。本次验证了浏览器输入与画面位置，未测量真实设备帧率。

代码提交：[d33aa15 — Let sustained wheel input scrub across the Work gallery](https://github.com/colinLH/PaperScientist/commit/d33aa15d8982b3a08b58a75e62d117395071c275)。
