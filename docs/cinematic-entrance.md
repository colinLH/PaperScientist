# 开场漫游、输入按钮与进展展示

2026-10-23

## 开场

访问 `/` 会进入 `/welcome`；末幕 Start 和“跳过开场”进入 `/?workspace=1`。原有 `?session=...`、`?project=...` 深链接直接进入工作台。工作台侧栏底部提供“重播开场”。

参考用户视频及 [Logartis](https://logartis.info/) 的逐幕镜头推进，制作了雾林、河谷、观测站、星图、山脊和日出六幕。场景使用程序生成的 Three.js 几何体，没有复制参考站的模型、图片或音乐。

- 一个滚轮手势推进一幕，180 ms 内的同向惯性归为同一手势；反向输入立即重定目标。
- 镜头沿同一条曲线路径往返，阻尼运动保留当前位置和速度，因此中途倒回不会重新播放整段动画。
- 键盘 ↑ ↓ / PageUp PageDown、Home / End 和章节按钮可导航；移动端提供上下滑动。减少动态效果模式直接切换视角。
- 移动时最多约 30 FPS，停止后不持续重绘。绘制缓冲最多 140 万像素；松树使用实例化，无动态阴影或后处理缓冲。隐藏页面暂停；进入工作台释放几何体、材质、WebGL 上下文和音频资源。工作台不加载 Three.js。
- 无 WebGL 或上下文丢失时保留轻量渐变、章节文字和进入入口。

相邻场景之间采用等功率交叉淡化，并用音频增益自动化继续平滑；中途反向从当前增益衔接。稳定章节只保留对应曲目，其余淡出后暂停。暂停保留 `currentTime`，倒回时继续原来的播放位置，不倒放、不跳回曲首。离开开场时淡出。

声音默认开启，载入时尝试启用音频；浏览器阻止自动播放时，在首次点击、按键或触摸时重试。滚轮也会尝试，但浏览器通常不把单独滚轮视为播放授权。声音按钮始终切换用户的开关选择，异步解锁完成不会覆盖用户刚选择的静音状态。前半段音量为零，进入观测站再渐入。页面隐藏时降低音量并暂停音频上下文。有关限制见 [MDN 自动播放指南](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)。

## 右侧文件预览

点击文件引用后，桌面端将主工作区均分为左侧对话和右侧预览，两边独立滚动，左侧输入框仍可编辑。拖动分隔线或用方向键调整宽度；双击分隔线或 Home 恢复均分。PDF 翻页、Markdown、表格、文本、图片、文件差异与撤销确认共用右侧面板。关闭按钮或 Escape 恢复布局；在输入框内 Escape 不关闭预览。切换会话会取消预览请求并清理面板。800 px 以下的屏幕使用可关闭的右侧抽屉。

网页实测覆盖 PDF、Markdown、CSV、文件差异、输入草稿保留、宽度调整、Escape 关闭和切换会话清理。预览内容仍通过既有后端权限与逐轮快照接口读取。

## 为什么原来中间输出少

检查既有论文会话：338 条 AI 消息，其中 337 条含工具调用，329 条工具调用消息没有可见正文。SSE 只能流式传输模型实际返回的正文，不能凭空补出进展。

这次强化了提示词：多步工作在开始、取得重要结果、出现失败或改变方向时，说明已核实发现、未决问题和下一步；不逐个叙述琐碎动作。新增 `report_progress` 工具，在模型只发工具调用时也能给出可见更新，与真实工具执行同批调用。更新持久化到时间线，按原顺序恢复；它不展示模型的隐藏推理，也不替代研究证据。单纯反复报告进展仍会触发无进展暂停保护。

实际更新频率仍受模型影响，不强制为简单问答制造额外步骤或额外模型调用。

## 发送／停止按钮

同一位置互斥展示：空闲、完成、暂停或出错时为发送箭头；排队、运行、恢复及等待关键回答时为停止按钮。切换会话、恢复历史和轮询状态都使用相同规则，归档对话不可执行。停止沿用保存历史和继续任务的机制。
