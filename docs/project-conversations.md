# 项目与多会话工作区

界面由 Python / Gradio 构建，使用深色项目侧栏、缩进的聊天标题、最近对话和底部输入栏。创建项目时使用中文或英文显示名称，内部生成独立 ID；已有仅有 ID 的项目与会话继续可用。项目下默认展示最近六个会话，可展开全部；支持按标题或项目名搜索。

每个 session 保存完整多轮历史，切换时恢复内容、产物、论文和项目状态，并清理当前未发送的输入及附件选择。从其他功能页新建或选择聊天会回到对话页。切换或停止会取消当前界面的响应流，已落盘的原始消息与工具结果保留。

输入栏「＋」保存附件到当前会话的工作区，登记来源与校验值。消息向模型携带明确的相对文件引用；界面展示文件名，附件不自动带入另一会话。单个文件上限 20MB。模型选择对下一轮生效，临时密钥仅用于调用配置。既有技能、论文库、子代理和产物下载入口保留。

## 标题和项目记忆

- 首条用户输入立即生成本地短标题；真实模型完成该轮时，将首问概括为简短主题/动作语句，保存后不再随追问改变。模型提炼关闭或失败时保留本地标题，不阻断聊天。旧会话可运行 `python scripts/summarize_session_titles.py` 查看候选，增加 `--apply` 使用配置的模型补齐标题；不会重写原始消息。
- 沿用 Marscode 的用户画像、项目记忆、近期主题、会话记忆分层和按用户/项目注入原则。每轮仍追加 session_memory；模型只将具有原文依据的稳定用户信息写入画像或项目约束。
- 增加项目内的会话摘要：保留决定、重要进展、未验证方案、待解决问题和下一步。同一会话贡献更新为同一个 memory ID 的新版本，不覆盖其他会话贡献。摘要保存原文消息 ID、精确引文、角色与来源会话，并保留近期来源链。
- 自动摘要统一标记 `unverified_summary`，提示词和界面明确区分用户确认的约束与助手建议。摘要不是已验证科学证据；完整历史与实验产物才是核验依据。
- 同项目新会话自动注入近期摘要和约束。不同项目不共享项目记忆；用户画像仍按用户共享。上下文为已确认项目记忆和会话摘要分别留出条目预算，更多内容可通过既有记忆检索恢复。独立审稿子代理继续排除这些共享记忆。

入口代码：`paperscientist/ui.py`、`ui_theme.py`、`workspace.py`。持久化与提炼：`store.py`、`memory.py`。新增 `/api/projects` 的 GET/POST 接口；原有会话 API 保持可用。

## 侧栏右键菜单

项目标题和会话行支持原生右键，也可以点击悬停时出现的「···」。键盘可用 Shift+F10 打开菜单，用方向键移动、Enter 选择、Esc 关闭。重命名、置顶、未读、归档对应 Alt+Ctrl+R、Alt+Ctrl+P、Ctrl+Shift+U、Ctrl+Shift+A；编辑输入框时不会劫持快捷键。

| 操作 | 行为 |
| --- | --- |
| 重命名 | 保存用户原始名称，手动命名后不再被模型自动标题覆盖 |
| 置顶、未读 | 在 SQLite 保存，置顶会话集中展示；打开会话自动标记已读 |
| 分区 | 可自定义或移回默认分区；仅改变导航分类，不改变项目归属及记忆范围 |
| 分叉（会话） | 可复制完整历史与附件，或创建仅共享项目记忆的空白分叉；文件、消息 ID 独立，子代理任务不复制，运行中的会话需先停止 |
| 分享（会话） | 生成可撤销的本机只读快照，仅含可见聊天；未来消息不会同步，附件文件、工具日志和项目记忆不随快照分享 |
| 复制、打开方式 | 复制名称、深链接、完整可见对话；新窗口打开、跳转项目记忆、导出 Markdown / JSON |
| 归档 | 在「归档」列表查看和恢复；项目归档会隐藏其所有会话，恢复项目保留原先单独归档的会话状态；归档对话只读 |
| 永久删除 | 先显示名称及影响范围，再明确确认。删除项目会清理其会话、子代理、附件、项目记忆、论文库和分享。删除会话会清理其子代理及全部来源关联记忆版本，不影响其他会话历史及其他项目数据 |

运行中任务在归档/删除前停止。文件操作限制在对应会话工作区，发现链接目录或越界路径时拒绝；数据库删除失败则回滚暂存文件。删除记录保留仅含 ID 的墓碑，旧窗口不能重新创建相同会话或项目。分享链接只在可访问当前本机服务的环境中有效，不会发布到公网。

菜单与工作区操作实现为 `sidebar.py`、`workspace_actions.py`，Python 负责 HTML、校验及持久化，Gradio HTML 的少量 JavaScript 仅衔接浏览器右键、键盘、剪贴板和对话框。新增 `/api/workspace/action`、`/api/workspace/navigation`、`/api/sessions/{sid}/transcript`、`/api/sessions/{sid}/markdown` 和 `/share/{token}`。升级仅新增数据表，兼容原有数据库。

## 验证

后端回归覆盖项目分组、中文名称持久化、搜索、历史恢复、父子/用户作用域、附件引用和隔离、首问标题稳定性、摘要版本、跨会话共享、跨项目隔离，以及提炼失败时原始记录仍保留。浏览器人工操作验证创建项目、连续追问、切换、附件预览与清理、模型选择和项目记忆卡片。真实 DeepSeek 验证记录另见 `docs/validation.md`。
