## 行为

最终一幕标题为“与科研 Agent / 一起出发。”，说明为“带上一个问题，开启你的下一项研究。”，保留原有 Start 入口和布局。

庭院金鱼提高金橙色与浅色鳞片对比，适当放大，并按各泳道的最小间距限制尺寸。点击实际水域内的金鱼附近，会同时产生涟漪和受惊加速；约 3.6 秒后逐渐减速恢复巡游。鱼的相位连续，沿原有不相交泳道到达另一位置，不重生、不淡出、不突然反向。连续点击延长反应，不重置位置。

点击坐标按绘画层的实际缩放与视差位置转换，岸边不触发水波。隐藏时停止接受水面点击。保持桌面 6 条、窄屏 4 条金鱼；使用原画布和动画时钟，无新增图像、依赖或动画循环。减少动态模式保留静态金鱼，禁用受惊移动。

## 验证

- 93 项 Node 开场测试、2 项 Python 页面与资源测试全部通过；其中 9 项池塘测试覆盖点击加速、恢复巡游、连续点击、平滑转向、身体和尾部间距、裁切边界、隐藏/释放及减少动态模式。
- 对 390×844、1280×720、2327×1105、3840×2160、640×360 五种尺寸分别模拟 1800 帧及重复点击，金鱼始终留在水域且保持间距。
- 实际网页点击两处金鱼附近；确认 DOM 中 `fishStartled=1`，第二次点击后 `ripples=1`，数量始终为 6。后续观察受惊状态恢复为 0，鱼游到另一位置。
- 网页核对最终标题、Start 链接和 390×844 窄屏布局；窄屏金鱼数为 4。页面错误日志为空，临时视口设置已恢复。
- 四个运行文件与 E:/agent 的 SHA-256 一致。网页截图和测试输出保存在本地验证目录，不发布私有会话数据。
